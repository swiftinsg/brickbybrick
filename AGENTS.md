# AGENTS.md — Focusedhouse

Read this first. Full requirements Q&A log is in `NOTES.md`.

## What this is
iOS 27.2 SwiftUI app for students and teenagers. On-device Apple Foundation Models splits a goal or to-do list into tasks, estimates how long each takes, and suggests a timed schedule. Everything stays on device: no backend, no accounts, no Google sign-in.

- Project is generated by xcodegen (`project.yml`). Add new files via `project.yml` sources, then run `xcodegen`.
- Work on branch `machine-learning`. Repo: https://github.com/chuahchengxi/Focusedhouse (public).

## Decisions (locked)
- **Two input modes (toggle):** Goal mode (one big goal → tasks spread over days) and Today mode (messy to-do dump → tidied, timed, fitted into today).
- **Free time:** iOS Calendar events (EventKit) as busy time. Google Calendar arrives via iOS account sync, so no Google API (onboarding tip explains setup). Optional self-set routine (school hours, bedtime). A Settings option asks for free time each time instead.
- **Output:** schedule lives in-app with checkboxes, plus an "Add to Calendar" button. A Settings toggle auto-adds to the calendar once a schedule is suggested.
- **Notifications:** local reminder at task start; end-of-task check-in "Done? / Need more time?".
- **Rescheduling:** default is plain-code push-back (+15/+30/+60 min shifts later tasks; overflow past bedtime → tomorrow). Plus a "Re-plan with AI" button.
- **Editing before accept:** full control: rename/add/delete tasks, change durations (auto-reflow), drag-and-drop on a timeline. "Try again" regenerates.
- **No Apple Intelligence** (older device / turned off): manual mode, where the student enters tasks and durations. Scheduling, calendar, reminders and check-ins still work; AI features are hidden.
- **Adaptive estimates (must be personalised):** save plans and actual durations (from check-ins) on device; feed per-category actual/estimate ratios into the model prompt.

## Build plan (phases, test each before the next)
1. **Core:** mode toggle → Foundation Models decomposition + estimates → schedule into routine free time → editable list with auto-reflow → SwiftData persistence. Manual-mode fallback.
2. **Calendar:** EventKit read of busy time, Add to Calendar, auto-add toggle, "ask each time" setting, Google-sync onboarding tip.
3. **Reminders & check-ins:** start notifications, end-of-task check-in, push-back, Re-plan with AI.
4. **Timeline:** drag-and-drop tasks between time slots.
5. **Adaptive estimates:** record actuals, inject per-category ratios into the prompt.

## Working rules
- Build one phase at a time; stop after each phase for the user to test.
- Keep it minimal: Apple frameworks only (FoundationModels, SwiftData, EventKit, UserNotifications). No third-party dependencies.
- Scheduling and push-back are plain deterministic code. Only decomposition, estimates and Re-plan use the model.
- Commit and push to `machine-learning` at the end of each phase.
